- [ ] **REQUIRED** 代码仓库全量 grep 确认无硬编码 API Key、密码、Token

## 九、回滚方案

### 9.1 触发条件（满足任一即触发）

- 错误率 > 5% 且持续 > 5 分钟
- QA P95 延迟 > 10s 且持续 > 5 分钟
- 数据库连接失败
- 核心功能（文档上传 / 搜索 / QA）不可用

### 9.2 回滚步骤

```bash
# 1. 切换到上一个镜像版本
docker compose -f docker-compose.prod.yml stop api web
docker tag ekb-api:<上一个 tag> ekb-api:latest
docker tag ekb-web:<上一个 tag> ekb-web:latest

# 2. 重启服务
docker compose -f docker-compose.prod.yml up -d api web

# 3. 验证健康检查
curl -f http://localhost:8000/healthz

# 4. 数据库回滚（仅 schema 变更时需要）
# pg_restore -U ekb -d ekb_prod /app/backups/<上线前备份>.dump
```

## 附录：快速命令参考

```bash
# 构建并启动
docker compose -f docker-compose.prod.yml build
docker compose -f docker-compose.prod.yml up -d

# 查看服务状态
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f api

# 健康检查
curl -f http://localhost:8000/healthz

# 数据库备份
docker exec ekb_postgres_1 pg_dump -U ekb ekb_prod > backups/$(date +%Y%m%dT%H%M%S).dump

# 停止服务
docker compose -f docker-compose.prod.yml down
```
