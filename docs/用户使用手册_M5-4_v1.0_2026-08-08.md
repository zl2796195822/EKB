## 1. 快速入门

### 1.1 访问地址与登录

1. 在浏览器中打开部署地址（默认：`http://localhost:5173`，生产环境由管理员提供）。
2. 首次访问自动进入主界面，无需单独登录（当前版本为单租户模式，多租户权限管控在 M2 阶段上线）。

| 页面 | 图标/入口 | 说明 |

| **知识库** | 📚 Knowledge | 管理知识库与文档 |

## 2. 知识库管理

### 2.1 创建知识库

1. 点击顶部导航 **知识库**。
2. 点击右上角 **「+ 新建知识库」** 按钮。
3. 填写知识库名称（必填）和描述（选填）。
4. 点击 **「创建」** 完成。

> **[截图占位：新建知识库对话框，填写名称与描述]**

### 2.2 上传文档

支持格式：**PDF / DOCX / XLSX / PPTX / TXT / MD**

1. 进入目标知识库，点击 **「上传文档」**。
2. 从本地选择一个或多个文件（支持批量上传）。
3. 确认后点击 **「开始上传」**，系统自动进行解析与向量化处理。

> **[截图占位：文件选择器及上传进度条]**

**注意事项：**
- 单文件建议不超过 50 MB。
- 上传后文档进入处理队列，处理时间取决于文档大小，通常在数秒至数分钟内完成。

### 2.3 查看文档状态

文档列表中每条记录右侧显示处理状态标签：

| 状态 | 说明 |
|------|------|
| `PROCESSING` | 正在解析、分块与向量化，请等待 |
| `READY` | 处理完成，可参与问答与检索 |
| `FAILED` | 处理失败，可查看错误详情后重新上传 |

> **[截图占位：文档列表展示三种状态标签对比]**

### 2.4 删除文档与知识库

- **删除文档**：在文档列表中点击对应文档右侧的 **「···」菜单** → **「删除」**，确认后文档及其所有向量数据将被永久移除。
- **删除知识库**：在知识库列表点击 **「···」菜单** → **「删除知识库」**，该操作会同时删除库内所有文档，**不可恢复**，请谨慎操作。

> **[截图占位：删除确认对话框]**

## 3. 智能问答

### 3.1 发起问答

1. 点击顶部导航 **问答**。
2. 在页面底部输入框中输入问题，按 **Enter** 或点击发送按钮。
3. 系统从已选知识库中检索相关片段，结合大语言模型生成答案。

> **[截图占位：问答主界面，含输入框与回答区域]**

**切换知识库范围**：在输入框上方的下拉菜单中选择参与问答的知识库（可多选）。

### 3.2 理解引用卡片

每条答案下方会展示 **引用来源卡片**，包含：

- 来源文档名称与页码/位置
- 原文片段摘要
- 相关度分数（0–1，越高越相关）

点击引用卡片可展开查看完整原文段落。

> **[截图占位：答案区域与引用卡片展开状态]**

### 3.3 多轮对话

系统保持当前会话上下文，可直接追问：

```
用户：公司的年假政策是什么？
助手：根据员工手册第 3 章，年假为 ……（附引用）

用户：那病假呢？
助手：同一手册第 4 章规定 ……（助手自动关联上下文）
```

若需开始全新话题，点击输入框左侧的 **「新对话」** 按钮清空上下文。

### 3.4 拒答场景说明

当知识库中找不到足够证据支撑答案时，系统会明确告知：

> *"根据当前知识库，未找到与该问题相关的充分依据，无法生成可靠答案。"*

这是系统的**防幻觉**机制，确保答案可溯源。遇到此情况，建议：
1. 确认相关文档已上传且状态为 `READY`。
2. 尝试换用更具体的提问方式。
3. 联系管理员补充知识库内容。

### 3.5 问答反馈

每条答案右下角提供反馈按钮：
- 👍 **点赞**：答案准确、有帮助
- 👎 **点踩**：答案有误或不满足需求（可选填文字说明）

反馈数据将汇总至运营页面，用于持续优化系统。

## 4. 文档检索

### 4.1 语义检索用法

1. 点击顶部导航 **检索**。
2. 在搜索框中输入关键词或自然语言描述，例如："合同违约条款"。
3. 点击 **「检索」** 或按 Enter。

系统使用向量语义匹配，即使关键词不完全一致，也能找到语义相近的内容。

> **[截图占位：检索页面输入与结果列表]**

### 4.2 结果解读

每条检索结果包含：

| 字段 | 说明 |
|------|------|
| **来源文档** | 文档名称及所属知识库 |
| **片段内容** | 匹配的文本段落 |
| **相关度分数** | 0–1 之间，建议关注 0.7 以上的结果 |
| **位置信息** | 页码或章节（如可用） |

结果默认按相关度降序排列，前 10 条。

## 5. 常见问题 FAQ

**Q1：上传文档后长时间停留在 PROCESSING 状态？**  
A：处理时间与文档大小及当前队列负载有关。若超过 10 分钟仍未完成，请刷新页面；若变为 FAILED，请联系管理员检查服务日志。

**Q2：问答结果没有任何引用来源？**  
A：请确认问答时已选择包含相关内容的知识库，且文档状态为 READY。

**Q3：检索结果相关度都很低（< 0.5）？**  
A：尝试使用更具体的描述性语句代替单一关键词，语义搜索对自然语言表达更友好。

**Q4：如何导出问答记录？**  
A：当前版本暂不支持导出，此功能列入后续迭代计划。

**Q5：系统支持哪些语言？**  
A：问答与检索支持中文和英文混合输入，底层模型对中文优化。

**Q6：知识库数据是否安全？**  
A：所有数据存储在本地部署环境，不上传至第三方。大语言模型调用通过配置的 API 端点进行，请确认与运维团队确认网络隔离策略。
