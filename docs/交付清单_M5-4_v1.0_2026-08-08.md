## 2. 数据库

### 2.1 当前开发环境

| 项目 | 说明 |
|------|------|
| **数据库类型** | SQLite |
| **文件路径** | `apps/api/ekb_dev.db` |
| **向量存储** | ChromaDB（本地持久化，`apps/api/chroma_data/`） |
| **适用场景** | 本地开发、功能验证、演示 |

### 2.2 生产环境切换说明

生产部署时需切换至 PostgreSQL + pgvector：

1. **安装依赖**：`pip install psycopg2-binary pgvector`
2. **修改环境变量**：
   ```
   DATABASE_URL=postgresql://user:password@host:5432/ekb_prod
   VECTOR_STORE=pgvector
   ```
3. **执行迁移**：运行 `alembic upgrade head` 完成 schema 初始化。
4. **pgvector 扩展**：在 PostgreSQL 中执行 `CREATE EXTENSION IF NOT EXISTS vector;`
5. **数据迁移**：如需从开发库迁移数据，使用 `scripts/migrate_sqlite_to_pg.py`（待补充）。

> ⚠️ **风险提示**：SQLite 不支持并发写入，生产环境必须完成 PostgreSQL 切换，详见第 6 节。

## 5. 环境配置

### 5.1 必需环境变量

在 `apps/api/.env`（或系统环境变量）中配置以下变量：

| 变量名 | 必填 | 说明 | 示例值 |
|--------|------|------|--------|
| `OPENAI_API_KEY` | ✅ | LLM API 密钥（OpenAI 兼容） | `sk-...` |
| `OPENAI_BASE_URL` | 可选 | 自定义 API 端点（使用代理或本地模型时） | `https://api.openai.com/v1` |
| `OPENAI_MODEL` | 可选 | 使用的模型名称 | `gpt-4o-mini` |
| `EMBEDDING_MODEL` | 可选 | 向量化模型名称 | `text-embedding-3-small` |
| `DATABASE_URL` | 可选 | 数据库连接串（不设则用 SQLite） | `sqlite:///./ekb_dev.db` |
| `VECTOR_STORE` | 可选 | 向量存储后端 | `chroma`（默认）或 `pgvector` |
| `CHROMA_PERSIST_DIR` | 可选 | ChromaDB 持久化目录 | `./chroma_data` |
| `MAX_TOKENS` | 可选 | 单次 LLM 调用最大 token 数 | `2048` |
| `RETRIEVAL_TOP_K` | 可选 | 检索返回片段数量 | `5` |
| `CIRCUIT_BREAKER_THRESHOLD` | 可选 | 熔断触发失败次数阈值 | `5` |
| `LOG_LEVEL` | 可选 | 日志级别 | `INFO` |
| `CORS_ORIGINS` | 可选 | 允许的跨域来源（逗号分隔） | `http://localhost:5173` |

### 5.2 前端环境变量

在 `apps/web/.env`（或 `apps/web/.env.local`）中配置：

| 变量名 | 必填 | 说明 | 示例值 |
|--------|------|------|--------|
| `VITE_API_BASE_URL` | ✅ | 后端 API 地址 | `http://localhost:8000` |
