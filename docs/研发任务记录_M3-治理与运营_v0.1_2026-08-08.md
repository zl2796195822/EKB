## 3. 关键设计决策

### M3-1 运营看板
- 从 `audit_logs`（`qa.ask` 动作）聚合问答量与 finish_reason 分布，计算准确率（stop+refusal/total）和拒答率。
- 从 `feedback` 表聚合满意度（UP/(UP+DOWN)）。
- 从 `review_items` 表统计 `PENDING` 数作为覆盖盲区指标。
- 仅统计当前租户数据，不跨租户泄露。

### M3-2 反馈闭环
- Feedback 表增加 `status`（PENDING/REVIEWED/RESOLVED）和 `annotation` 列。
- 状态流转由审计能力（`audit:read`）持有者操作。
- **关键约束**：反馈标注不自动覆盖生产知识——标注仅记录处理结论，知识更新仍需人工操作文档 CRUD。

### M3-3 低置信度审核队列
- `ReviewItem` 表关联 `conversation_id`/`message_id`/`question_preview`/`answer_preview`/`evidence_summary`。
- QA 拒答（`finish_reason=refusal`，`confidence=low`）时自动入队，无需用户操作。
- 审核项可流转 PENDING → REVIEWED → RESOLVED，记录 `resolution` 和 `resolved_by`。

### M3-4 LLM 熔断器
- `CircuitBreaker` 单例：连续失败达 `failure_threshold`（默认 5）→ OPEN（短路）；经 `recovery_timeout`（默认 60s）→ HALF_OPEN（放一个探测）；探测成功 → CLOSED，失败 → 回 OPEN。
- `llm.chat()` 入口先检查熔断器状态，开闸时抛 `CircuitOpenError`（不发往外网）。
- 降级路径不变：`rewrite_query` 失败返回原始 query；`generate_answer` 失败降级到 demo 拼接。

### M3-5 存储配额
- `Tenant.quota_storage_docs`（0=不限）；上传端点校验，超额返回 429 `STORAGE_QUOTA_EXCEEDED`。
- QA 配额已在 M2-7 实现（`quota_daily_qa` + 429 `QUOTA_EXCEEDED`）。
- 外部模型调用配额由熔断器限流保护。

### M3-6 文档版本与差异
- `DocumentVersion` 表存储版本快照：`version`/`checksum`/`chunk_count`/`content_snapshot`（chunk 摘要列表含 `content_hash`/`content_preview`/`section_path`）。
- `ingest_document` 成功时自动创建版本快照。
- `GET .../versions` 列出历史版本；`GET .../diff?from=1&to=2` 按 content_hash 比对 added/removed/unchanged。

### M3-7 增量同步
- `SyncSource` 表记录外部数据源：`source_type`（WEBDAV/TICKET/API）、`cursor`（高水位标记）、`status`（ACTIVE/PAUSED/SYNCING/FAILED）、`retry_count`。
- `POST /admin/sync/sources` 创建源；`POST .../run` 触发同步（MVP：标记成功并推进游标）。
- `record_sync_result` 记录同步结果：成功推进游标+清零重试；失败累加重试，3 次后标记 FAILED。
- 实际外部拉取由外部适配器完成，API 层提供游标管理和失败重试基础设施。

### 代码卫生（2026-08-08 修复）
- `ruff check` → 0 错误（原 38 个：import 排序、行超长、未用 import，已全部修复）。
- `ruff format` → 全部已格式化。
- `test_qa_returns_refusal_when_no_evidence` 原标注"known LLM-flake"，根因并非 LLM 非确定性：seed-v2 种子知识充实后，"zzz不存在的火星语问题qqq" 中的 CJK bigram（如"存在"）与语料产生词法命中，触发了正常的 BM25 召回并作答。修复方式：将拒答测试的查询改为纯 ASCII 无意义串（"xyzzy wumpus frobnitz quux"），与种子语料零重叠，门禁行为稳定复现。
