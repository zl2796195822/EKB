## 1. 产品是什么

**EKB（Enterprise Knowledge Base）是面向中大型组织的企业级知识库 + 检索增强问答（RAG）平台**，同时服务内部员工和外部客户租户，覆盖"文档沉淀 → 8 源检索 → AI 问答带证据 → 质量运营闭环"全链路。

本前端工程 `apps/web` 实现 EKB 的主 Web 门户，包含 4 个核心入口页：**问答助手（QA）、知识库管理（KB）、检索中心（Search）、运营看板（Ops）**。

---

## 2. 为谁做（用户画像）

| 用户角色 | 典型场景 | 核心诉求 |
|---|---|---|
| 内部知识员工（主要） | 查制度、找流程、问政策 | 答案准确、有引用、能回到文档原文 |
| 外部客户租户 | 查阅自己租户授权的知识 | 数据隔离、权限边界清晰、体验专业 |
| 知识管理员 | 创建 KB、上传文档、管理权限 | 批量操作高效、入库状态透明 |
| 运营/质量负责人 | 看问答质量、处理低置信队列 | 指标可量化、异常可追踪 |

---

## 3. 产品定位关键词

1. **信任优先**：每个 AI 输出都必须回到证据（引用），不伪装确定性事实
2. **高效工作**：搜索、筛选、批量操作和键盘路径优先；减少无意义跳转
3. **边界可见**：租户、知识库、可见性、角色在关键操作处持续可见
4. **状态完整**：每页必须具备加载 / 空数据 / 错误 / 无权限 / 处理中 / 成功 六态
5. **克制动效**：动效只用于流式输出、状态反馈和层级过渡，不做装饰

## 4. 产品语气（Voice & Tone）

| 场景 | 语气 | 示例 |
|---|---|---|
| 正常操作 | 安静、专业、克制 | "正在加载授权知识库…" |
| 成功状态 | 温和肯定，不夸张 | "已发送反馈，感谢帮助我们改进" |
| 错误状态 | 明确、可执行、不甩锅 | "登录失败，请检查邮箱密码或联系管理员" |
| 权限受限 | 中性不暴露存在性 | "部分结果因权限不可见" |
| AI 置信表达 | 诚实标注边界 | "以下答案基于检索结果生成，仅供参考" |

禁止文案：拟人化自称（"我是 EKB 助手"）、过度营销词（"强大"、"智能"）、表情包或 emoji 装饰（除产品规定状态图标外）。

## 6. 本期范围（M1 · Galaxy Motion v4）

- ✅ 登录 + 租户识别
- ✅ 问答助手页：SSE 流式 + 引用证据链 + 会话历史 + 反馈

不在本期范围（M2+）：SSO 多租户切换、成员权限管理页、审计日志完整页、模型与策略配置页。
